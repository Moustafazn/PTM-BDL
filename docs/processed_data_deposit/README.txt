PTM-BDL processed datasets and saved data partitions

This deposit contains unchanged copies of the final processed modelling tables and their saved production training, validation and test partitions for the manuscript A site-resolved post-translational modification framework for drug-response analysis. The tables are harmonised study inputs derived from public resources and published studies. No raw experimental downloads are included.

The EGFR/ERBB2 table contains 951 context rows and phosphorylation and glycosylation inputs. The HeLa/HDAC table contains 3,374 context rows and phosphorylation and acetylation inputs. The K562/CML table contains 10,656 context rows and phosphorylation inputs. Contexts are cell-line, drug and target-protein combinations. The HeLa/HDAC and K562/CML tables expand shared cell–drug endpoints over two and three target proteins, respectively, so context counts do not represent independent drug-response measurements. Case-study names denote reference biological settings and the cohorts include additional cell lines.

Each file ending in _processed.csv is the final multimodal_dataset.csv used by the corresponding training script, with a case-specific filename supplied here for upload. Each matching _split_indices.json contains zero-based row positions into that CSV. Keep row order unchanged when applying these indices. The saved partitions contain 665/143/143 rows for EGFR/ERBB2, 2361/506/507 rows for HeLa/HDAC, and 7458/1599/1599 rows for K562/CML, in training/validation/test order. These are the production partitions and are not the separate cross-validation or held-out-drug folds.

ln_ic50 contains the natural logarithm of IC50 expressed in micromolar units before transformation. resistance_label is the processed binary response label. Cell, drug, target, sequence and structure identifiers link the records to their molecular context. PTM inputs retain baseline and treatment-associated change values, including source-derived and propagated profiles. Secondary PTM columns use configured slots; column names alone must not be treated as universally verified residue assignments. propagation_confidence records the source-matching and propagation heuristic rather than an experimental uncertainty estimate.

MANIFEST.json lists the exact original repository paths, file sizes, SHA-256 checksums, row counts and column names. The copied files have not been filtered, reordered, recomputed or otherwise altered. Intermediate processed tables and the alternative RPPA-injected K562 table are not included.

The code and source-data acquisition guide are maintained at https://github.com/Moustafazn/PTM-BDL. The guide is docs/DATA_DOWNLOAD_GUIDE.md. Case-study PTM configurations are under src/case_studies/<case_study>/config.yaml, and dataset loading is implemented in src/ptm_bdl/data/dataset.py. To use these tables with the existing pipeline, restore each _processed.csv to data/processed/<case_study>/multimodal_dataset.csv and each split file to data/models/<case_study>/split_indices.json.

This deposit supplies processed tables and saved production splits. Fixed sequence, structure-derived and chemical feature arrays, trained model checkpoints and result JSON files are not included in this package, so these tables alone are not a complete frozen inference environment. Original resources and publications should be acknowledged when reusing the derived data, with the applicable source terms respected.
